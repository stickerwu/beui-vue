# 效果验收

此版本以 beUI 提交 `c0a936f` 为基准，覆盖 122 个组件与 38 个区块。每个目录条目都可以运行 Vue 示例、查看 API，并打开对应的上游源码。

## 效果对照

- [172 组上游与 Vue 演示截图](./review/index.html)。在浅色、减少动态效果下采集，可按组件名筛选并放大。两侧沿用各自的演示，文案、数据和控件差异会保留在图中。
- [六个样板的关键帧与像素差异](./review/frames/index.html)。使用同一视口和数据，在明暗主题下分别采集起始帧、80 毫秒和 780 毫秒的画面。场景包含按钮按压、切换标签、移动滑块、加入通知、检查数据点和切换 Shader 帧。

## 验收范围

浏览器测试覆盖 Chromium、Firefox、WebKit 及模拟触屏环境，检查组件交互、服务端首屏和客户端接管。安装测试用实际打包的 `.tgz` 在独立 Vite 和 Nuxt 工程验证。

真实设备的拖拽松手、快速反向切换和动效中断需要逐变体审看。维护者在 `ports*.json` 记录关键帧、键盘、触屏、减少动态效果四项证据，目录随记录更新通过数。正式版 `1.0.0` 的发布检查要求所有变体均已通过。
