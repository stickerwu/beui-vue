## 从一个交互开始

拖动[对比滑块](./components/motion/before-after-slider)查看两侧内容，切换[标签页](./components/motion/tabs)观察指示器如何跟随，或把指针移到[折线图](./charts/line-chart)上读取数据。每个示例都附有 Vue 源码、API 和上游演示。

## 在哪里使用

beui-vue 面向 Vue 3.5 及以上的 Vue 3 项目，提供 TypeScript 类型和编译好的 CSS，支持 Vite 和 Nuxt SSR。当前预览版从 [GitHub Release](https://github.com/stickerwu/beui-vue/releases/tag/v0.1.0-alpha.0) 安装。

## 项目与上游

本项目由 stickerwu 独立维护，动效和交互设计源自 beUI 及其贡献者，采用 MIT 许可证。你可以查看 [beUI 原版](https://beui.dev/)、[Vue 移植源码](https://github.com/stickerwu/beui-vue)、[Gitee 镜像](https://gitee.com/stickerwu/beui-vue)和[逐变体验收进度](./verification)。
