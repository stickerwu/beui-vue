# beui-vue

## 0.1.0-alpha.1

First release on npm (`npm install beui-vue@next`).

- Editable Table keeps its row handles on their row after the table scrolls.
- Upload Queue rows slide into place when a row is removed.
- Press feedback is back on components that used `while-tap` (Checkbox, Radio Group, Color Selector, Date Range Picker, Animated Sidebar, Wallet Card, Prediction Market Card, Feedback Widget, Not Found, the calendar heatmaps).
- Prompt Input: the model menu unfolds from its trigger and the actions popover reveals from its corner, as on beui.dev.
- PopoverMorph moves focus into the panel when it is opened with the keyboard.

## 0.1.0-alpha.0
